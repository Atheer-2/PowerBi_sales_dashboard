# PowerBi_sales_dashboard
Sales Dashboard  Interactive Power BI dashboard analyzing sales and profit by category, region, and sub-category. The dataset comes from a Power BI course. The design, color palette, titles, and formatting are my own.

The dashboard summarizes total sales (2.30M), total profit (286K), and total quantity sold (38K). A state and category slicer updates every number and chart.

Visuals:                                                                                                                                                            
Sales by Category (donut chart)
Profit by Category and Region (stacked bar chart)
Profit by Sub-Category (column chart)

Interactivity: All visuals are linked, so selecting one element filters the rest.

Notes: Small segments in the stacked bar chart do not display labels. Hover over them to see the values.
